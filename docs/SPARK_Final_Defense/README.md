# SPARK final-defense thesis draft

Build this folder independently with `build.bat`, or run `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex` from this directory. Output: `main.pdf`. TeX Live with latexmk and BibTeX is required. There are no inputs from the proposal or mid-defense folder.

Edit `FrontPages/`, `Chapters/`, `Figures/`, and `BackPages/references.bib`. The KEC formatting assets, institutional logo, project title, four authors, supervisor, coordinator, and department leadership follow the preserved proposal. Approval/declaration forms are unsigned preparation copies. No defense date is invented.

This is a thesis draft, not a completed hardware or clinical study. Pending sections state the artifacts needed before submission. The evidence folder freezes archived results and source hashes as inspected on October 14, 2026. Reading an artifact does not reproduce its experiment; offline window metrics do not establish wrist-worn event sensitivity or elderly clinical performance.

Human fall detection remains primary. The planned MuJoCo appendix is a separate exploratory study with 40 episodes, half held out, and no executed simulation. Physical robot evaluation remains future work.
