\section*{A.1 \quad Nepal Cohort 34-Activity Data Collection Protocol}

The SPARK self-collected dataset protocol is executed in the KEC Robotics / Electronics laboratory using high-density gymnastic crash mats ($20$\,cm thickness) with $N=12\text{--}20$ volunteers (sample size grounded in clinical pilot standards \cite{julious2005sample}). The protocol spans 34 activities:

\textbf{15 Fall Activities across 8 Biomechanical Mechanisms (Positive Class, 3 trials each):}
\begin{itemize}
    \item \textbf{Forward Falls (F01--F03)}: Trip while walking, slip on slick surface, stumble during recovery.
    \item \textbf{Backward Falls (F04--F06)}: Slip on heels while walking, backward loss of balance from chair, sit-to-stand collapse.
    \item \textbf{Lateral Falls (F07--F09)}: Left and right sideways slip while turning, stumbling sideways over obstacle.
    \item \textbf{Syncope / Fainting Falls (F10--F12)}: Vertical collapse with delayed recovery, wall-sliding collapse.
    \item \textbf{Rotational Twist Falls (F13--F15)}: Torso twist slip during rapid turn, ladder/step misstep twist.
\end{itemize}

\textbf{19 Activities of Daily Living (ADLs) (Negative Class, 3--5 trials / 2-minute continuous blocks):}
\begin{itemize}
    \item \textbf{Locomotion (D01--D06)}: Slow walk, normal walk, fast brisk walk, jogging, ascending and descending stairs.
    \item \textbf{Postural Transitions (D07--D12)}: Sitting on chair, standing up, lying on bed, getting up from bed, squatting, bending to tie shoes.
    \item \textbf{Dynamic Upper-Limb ADLs (D13--D19)}: Vigorous clapping, arm waving, sweeping floor, drinking water, typing, coughing/sneezing while seated, stumbling with reflex recovery.
\end{itemize}

The node is secured to the dorsal wrist ($x$: distal, $y$: anterior, $z$: dorsal normal) sampling 6 axes at 200\,Hz, outputting SisFall-compatible CSV schemas (`Ax, Ay, Az, Gx, Gy, Gz`).
