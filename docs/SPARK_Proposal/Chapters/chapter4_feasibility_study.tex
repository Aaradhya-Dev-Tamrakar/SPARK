\chapter{\scshape Feasibility Study}

\section{Technical Feasibility}

SPARK is technically feasible because every subsystem has been implemented, benchmarked, and verified across both simulated and hardware environments with 48 automated test suites passing cleanly.

\textbf{On-Device Quantized CNN Inference on ESP32-S3.}
TensorFlow Lite Micro has been widely validated on Cortex-M4 and Xtensa microcontrollers \cite{david2021tensorflow}. The ESP32-S3 dual-core processor (240\,MHz, 512\,KB SRAM, 16\,MB flash) with vector extensions provides extensive compute headroom. Full INT8 post-training quantization compresses the SPARK 1D CNN model to \textbf{18.5\,KB} of flash ($87.7\%$ compression vs.\ FP32), requiring less than 8\,KB of tensor arena RAM during inference. The complete Layer~1 pre-filter and sliding window ring buffer execute within the 200\,Hz ISR with sub-millisecond execution overhead.

\textbf{Two-Layer Gated Architecture \& Power Feasibility.}
Layer~1 threshold evaluation incurs negligible CPU overhead. By gating the CNN inference behind the magnitude-duration condition ($|a| > 2.5$\,g for $>300$\,ms), the neural network is invoked only during candidate impact dynamics (fewer than 5 events per hour during normal ADLs). In event-gated BLE mode, the node operates at an average current draw of $35\text{--}60$\,mA, delivering $16\text{--}28$\,hours of continuous protection from an 1100\,mAh pouch cell.

\textbf{Local Companion Gateway Hardware Acceleration.}
The companion laptop (Acer Swift Go 16 with Intel Core Ultra 7 155H) executes real-time gradient explainability without cloud dependency. Benchmarks using Intel OpenVINO 2026.3 confirm: Intel CPU (AVX-VNNI) achieves $0.131$\,ms per window ($7{,}618$\,windows/s), Intel Arc GPU reaches $0.200$\,ms ($4{,}993$\,windows/s), and the Intel AI Boost NPU runs at $0.383$\,ms ($2{,}610$\,windows/s).

\textbf{Sample Size \& Cohort Protocol Feasibility.}
Clinical pilot methodology by Julious \cite{julious2005sample} establishes $N=12\text{--}20$ subjects as an optimal, statistically defensible cohort size for pilot feasibility studies. Collecting 34 standardized activities (15 falls across 8 mechanisms, 19 ADLs) with $N=12\text{--}20$ Nepali volunteers at KEC provides sufficient kinematic diversity while maintaining safety on $20$\,cm gymnastic crash mats.

\textbf{Software Stack \& Repository Maturity.}
All core algorithms, explainability modules, BLE GATT receivers, REST dashboard servers, and PDF report generators are fully implemented with 48 unit tests passing under \texttt{pytest} with zero lint errors.
